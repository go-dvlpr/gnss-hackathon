# Распознавание жестов ASL

Локальный прототип на Go 1.25 и обычном JavaScript. Браузер загружает MediaPipe Hand Landmarker с CDN. Укажите ключ в локальном файле `.env` как `OPENAI_API_KEY`. Разрешите браузеру доступ к камере при первом запуске записи.

```zsh
set -a
source ./.env
set +a
go run .
```

Откройте [http://127.0.0.1:8080](http://127.0.0.1:8080). Без ключа можно проверить камеру и точки кисти.

1. Нажмите «Начать запись» и дождитесь статуса записи.
2. Покажите жесты. MediaPipe обрабатывает камеру локально с частотой 6 кадров в секунду.
3. Нажмите «Остановить и распознать». Браузер отправит один запрос в `POST /api/recognize` со всеми отсчётами записи.

Каждый отсчёт содержит время от начала записи и до двух кистей по 21 точке `[x,y,z]`. Координаты MediaPipe передаются целыми в тысячных долях. Паузы и отсчёты без видимых кистей остаются в массиве. Если кистей не было во всей записи, запрос не выполняется. Фото, видео и звук не передаются. «Выключить камеру» отменяет запись или ожидание ответа.

Сервер добавляет краткую сводку сгибов пальцев, положения запястий и сближения кистей, затем отправляет сводку и полный массив координат в OpenAI Responses API одним текстовым запросом и возвращает список жестов. Модель выбирается через `OPENAI_MODEL`, по умолчанию `gpt-6.2-sol`.

## Локальные записи запросов

Чтобы сохранить точный JSON запросов к модели, установите в `.env` `OPENAI_REQUEST_LOG_DIR=request-logs`. Сервер сохраняет тело запроса до вызова OpenAI и выводит путь к файлу. В файле есть координаты, рассчитанные признаки и параметры модели. Заголовки HTTP хранятся отдельно от тела запроса. Каталог `request-logs/` исключён из Git.
