# AI UI/UX lecture: Claude skills

В архіві 23 скіли для роботи з UI, UX і брендингом у Claude. Вони розкладені по папках за джерелом.

## Який для чого

### Рев’ю і якість

| Скіл | Для чого | Папка |
|---|---|---|
| `design-critique` | Структурований фідбек на макет: зручність, ієрархія, послідовність | anthropic-design-plugin |
| `heuristic-review` | Аудит за 10 евристиками Нільсена: проблема, евристика, критичність 1–4, рішення | own |
| `usability` | Чи можна інтерфейсом користуватися: евристична оцінка, закони UX, патерни навігації, форм і таблиць | design-for-ai |
| `accessibility-review` | Аудит доступності за WCAG 2.1 AA: контраст, клавіатура, тач-зони, скрінрідер | anthropic-design-plugin |

## Як підключити в Claude Code

Скопіюйте папку потрібного скіла:

- у `~/.claude/skills/`, якщо скіл потрібен лише вам;
- у `.claude/skills/` в репозиторії, якщо скіл потрібен усій команді.

Після цього почніть нову сесію Claude Code. Скіл викликається сам, коли запит збігається з його описом, або явно: `/назва-скіла`.

Два скіли мають однакову назву `design-system`. Якщо потрібні обидва, одному з них змініть назву папки і поле `name` у `SKILL.md`.

## Звідки скіли

- `skills/anthropic-design-plugin/`: плагін `design` від Anthropic, версія 1.2.0. Окремого файла ліцензії в папці плагіна немає, умови дивіться в репозиторії плагіна.
- `skills/anthropic/`: скіли Anthropic, ліцензія Apache 2.0 (файл `LICENSE.txt` у кожній папці).
- `skills/ui-ux-pro-max-pack/`: набір UI UX Pro Max, https://github.com/nextlevelbuilder/ui-ux-pro-max-skill. Умови використання дивіться в репозиторії.
- `skills/design-for-ai/`: набір design-for-ai, https://github.com/ryanthedev/design-for-ai. Умови використання дивіться в репозиторії.
- `skills/own/`: власні скіли авторки лекції.

## У цьому репо

Скопійовано з архіву лекторки L17 (2026-11-20) у `.claude/skills/` пласко, бо вкладені папки Claude Code не бачить. Зміни:
- `design-system` з ui-ux-pro-max-pack перейменовано на `design-tokens` (папка й `name`), бо з такою назвою вже є скіл Anthropic;
- у `heuristic-review` прибрано зайвий другий frontmatter: його `description` дорівнював назві, і скіл не тригерився;
- не взято `brand-guidelines`, бо це брендбук Anthropic: він фарбував би все в їхні кольори;
- не взято `design`, бо для генерації картинок потрібен ключ до зовнішнього сервісу.
